# pet-ui.ttf

Bundled UI face for speech bubbles / particles (SIL Open Font License 1.1).

Built as a glyph subset of:

- [Noto Sans SC](https://github.com/notofonts/noto-cjk) Regular
- [Noto Sans](https://github.com/notofonts/latin-greek-cyrillic) (Greek `ω`)
- [Noto Sans Symbols 2](https://github.com/notofonts/symbols) (`♡❤` …)
- [Noto Sans Math](https://github.com/notofonts/math) (`∇`)
- [Noto Music](https://github.com/notofonts/music) (`♪`)

Emoji outside the subset fall back at runtime to system faces (not redistributed).
